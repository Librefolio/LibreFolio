# F-004 — App Shell & Navigation

## What it does
The persistent application shell wrapping all authenticated pages. Includes a collapsible sidebar with navigation links (Dashboard, Brokers, Transactions, Tools, Assets, FX, Files, Settings — `Sidebar.svelte`, 2026-11-07), a top header bar with theme toggle and language selector, and a footer. On mobile, the sidebar is hidden behind a hamburger menu. The shell enforces authentication — unauthenticated users are redirected to login.

## Layer breakdown
**Frontend**: `frontend/src/routes/(app)/+layout.svelte` (auth guard + shell wrapper), `frontend/src/lib/components/layout/` (Header, Sidebar, LanguageSelector, HelpMenu, PageBackButton…), `frontend/src/lib/stores/app/navigationStore.ts` (the in-app back-navigation stack behind `goBack()`)

## Implementation notes
- Auth guard in `(app)/+layout.svelte`: a 401 from `/auth/me` goes to `loginUrl()` = `/?redirect=<path>` (the login is
  the root page; there is no `/login` route) — [[features/F-001]]. *2026-11-07 lint: the page said `+layout.ts` →
  `/login`.*
- Sidebar collapse state persisted by `Sidebar.svelte` in user-scoped localStorage (`sidebar-collapsed`);
  `navigationStore` is the back-navigation stack, not the sidebar state
- Mobile: hamburger menu with `openMobileMenu()` helper used in E2E tests
- `lucide-svelte` for all nav icons
- Brand color `#1a4031` (libre-green) used in sidebar header
