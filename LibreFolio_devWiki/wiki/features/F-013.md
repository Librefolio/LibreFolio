# F-013 — BRIM Broker Parser Plugins

## What it does
The registered collection of broker report parsers and the Generic CSV fallback. Each
plugin extends `BRIMProvider`, is auto-discovered through `BRIMProviderRegistry`, and
returns a `BRIMParseOutput` from `parse()`. The current provider catalog is maintained in
the linked developer documentation rather than frozen as a count in this page.

## Layer breakdown
**Backend**: `backend/app/services/brim_providers/` contains the concrete parsers,
normally one module per supported source, plus `broker_generic_csv.py` as the fallback.

Sample reports in `backend/app/services/brim_providers/sample_reports/` for testing.

## Dependencies
- [[F-012]] BRIM Framework — abstract base class and pipeline
- [[F-059]] Provider Registry Pattern — auto-discovery via `@register_provider`

## Enables
- [[F-049]] BRIM Import UI — frontend staging modal consumes parsed results

## Implementation notes
- Fake asset ID flow: plugins output transactions with reserved **positive high integers**
  beginning at `FAKE_ASSET_ID_BASE`; the multi-file merge remaps them before resolution
- `plugin_version` field on each plugin — cache invalidation if plugin logic changes
- `detected()` method scans file headers/structure to identify the broker without user selection
- Warnings list (non-fatal): missing prices, unknown asset types, skipped rows
- All plugins tested via `./dev.py test external brim-providers`
