# F-024 — Asset CRUD

## What it does
Full CRUD for financial assets (stocks, ETFs, bonds, crypto, etc.). Assets store display name, currency, asset type, and classification params (sector, geography, etc.) as JSON. Asset type is one of eleven base values — STOCK, ETF, BOND, CRYPTO, FUND, CROWDFUND, HOLD, COMMODITY, REAL_ESTATE, INDEX, OTHER — or one of seven subtypes: ETF_STOCK, ETF_BOND, ETF_COMMODITY, ETF_REAL_ESTATE, ETF_CRYPTO, ETF_MONETARY and CROWDFUND_REAL_ESTATE (checked against `backend/app/db/models.py` at `083ed26dc`; the two-level taxonomy, its select and its icons: [[decisions/asset-type-two-level-taxonomy]]). INDEX forbids transactions.

The `FAAssetCreateItem` schema accepts the asset profile plus optional initial provider assignment so both steps can be done in one API call.

## Layer breakdown
**Backend**: `backend/app/api/v1/assets/crud.py` (POST `/assets`, GET `/assets/query`, GET `/assets/{id}`, PATCH `/assets/{id}`, DELETE `/assets` bulk), `backend/app/services/assets/crud.py` (`AssetCRUDService`), `backend/app/db/models.py` (`Asset` model)

**Frontend**: `frontend/src/routes/(app)/assets/` — list + `[id]` detail pages, `frontend/src/lib/components/assets/AssetModal.svelte` (1328 lines — create/edit modal with provider auto-assign)

## Implementation notes
- `GET /assets/query` supports filters: `active`, `asset_type`, `currency`, `search` — returns `FAinfoResponse` list
- `classification_params` JSON blob: `{sector, country, isin, ...}` — flexible, not schema-enforced at DB level
- Bulk delete: `DELETE /assets` with list of IDs
- `Asset.active` flag: when `False`, scheduler skips sync (Phase 8). An inactive asset stays selectable in every asset
  picker, sorted last with a badge, and picking one does not reactivate it (beta decision D4)
- **Merge** (`POST /assets/merge`, `AssetMergeModal`; `0e07359b4`, 2026-08-08, shipped in 1.1.0): folds a duplicate
  into the asset to keep. Transactions, prices, events and the provider assignment move; every identifier survives,
  the losing values in `identifier_other`; the source is deleted. `dry_run` returns the counts the dialog shows first.
  Reached from the asset list («Merge with…») and from the import wizard. Why: [[decisions/asset-identity-quoted-code-leads]];
  its ordering traps: [[problems/asset-merge-cascade-deleted-the-migrated-events]]
