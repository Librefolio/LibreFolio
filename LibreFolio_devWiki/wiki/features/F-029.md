# F-029 — Asset Metadata Refresh

## What it does
Fetches up-to-date metadata (full name, sector, country, ISIN, asset type) from the provider for an asset and shows a diff between the stored values and the provider's current data. Users can choose to apply the update or keep existing values. Useful for correcting auto-filled data or refreshing after a corporate action.

## Layer breakdown
> **2026-11-07 lint — the refresh route is gone.** The bulk metadata refresh (`POST /assets/provider/refresh`,
> `FABulkMetadataRefreshResponse`, service `backend/app/services/assets/metadata.py`) was removed in 1.3
> (`d5e467847`, 2026-11-04): the form's **Ask Provider** and a search pick read the metadata through the dry-run
> probe, `POST /assets/provider/probe` with the `metadata` operation (`_probe_metadata()` in
> `backend/app/services/assets/provider_management.py`, calling the provider's `fetch_asset_metadata()`), and the
> comparison is computed in the browser (`assetMetadataComparison.ts`) — [[decisions/api-routes-removed-without-deprecation]].
> The original line below is kept as history.

*Before 1.3*: **Backend**: `backend/app/api/v1/assets/providers.py` (POST `/assets/metadata/refresh` bulk), `backend/app/services/assets/metadata.py` (`AssetSourceManager.fetch_asset_metadata()`), `backend/app/schemas/assets/metadata.py` (`FAAssetMetadataResponse`, `OldNew` diff fields)

**Frontend**: `frontend/src/lib/features/assets/ProviderComparisonModal.svelte`, `frontend/src/lib/features/assets/assetMetadataComparison.ts`, **Ask Provider** in `AssetModal.svelte`

## Implementation notes
- `fetch_asset_metadata()` is optional on providers — yfinance, JustETF and Borsa Italiana implement it (plus the test
  `mockprov`; checked 2026-11-07)
- Metadata cache TTL: 30 min
- `OldNew[T]` schema in `common.py`: `{old: T, new: T}` — used for each changed field in the diff
- `FABulkMetadataRefreshResponse` wrapped per-asset results (removed with the route in 1.3)
