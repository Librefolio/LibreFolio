# F-032 — Asset List View dual view

## What it does
The `/assets` page showing all configured financial assets in two interchangeable views: a card grid (`AssetCard.svelte`) and a data table (`AssetTable.svelte`). View toggle persisted in localStorage. Each card shows asset type badge, display name, currency, current price, delta % for multiple periods, and a mini price chart. The page includes "Add Asset", "Sync All", and bulk-delete actions.

## Layer breakdown
**Frontend**: `frontend/src/routes/(app)/assets/+page.svelte`, `frontend/src/lib/components/assets/AssetCard.svelte` (287 lines), `frontend/src/lib/components/assets/AssetTable.svelte` (265 lines), `frontend/src/lib/components/assets/AssetSyncModal.svelte`

## Implementation notes
- Dual view toggle: localStorage key `assets-view-mode`
- `AssetTable` shows multi-period Δ% columns (1d, 1w, 1m, 3m, 1y)
- `AssetCard` includes `PriceChartCompact.svelte` (58 lines) — minimal sparkline
- `active` filter toggle to show/hide archived assets
- **Name cell escaped (2026-09-30)**: `AssetTable`'s `html` Name cell interpolated the display name and `icon_url` raw
  — a stored XSS shipped in v1.1.0 (assets are global, so one user's hostile name ran in every browser); now
  `escapeHtml` at the source, guarded by two gates and an E2E — [[decisions/html-escape-at-the-source]]
- **Type filter** offers every `AssetType`, subtypes included, grouped by family (gate `assetTypeTables.test.ts`) —
  [[decisions/asset-type-two-level-taxonomy]]
- The list publishes its visible order (filters, view, table sort) for the detail page's ‹ n/N › navigation —
  [[features/F-033]]
