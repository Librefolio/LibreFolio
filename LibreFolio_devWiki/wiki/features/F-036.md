# F-036 — Provider Comparison Modal

## What it does
A modal dialog that shows a side-by-side diff between the asset's current form values and the values returned by the provider (a Search Online pick, or **Ask Provider**). Each changed field is highlighted. Users can apply the provider's values, keep the current ones, or cherry-pick field by field.

## Layer breakdown
**Frontend**: `frontend/src/lib/features/assets/ProviderComparisonModal.svelte`, the diff built by `assetMetadataComparison.ts`, the queue of questions in `providerComparisonQueue.ts`

## Dependencies
- [[F-029]] Asset Metadata Refresh — modal is shown after a metadata fetch returns differences

## Enables
- (UX utility — no downstream dependencies)

## Implementation notes
- *2026-11-07 lint*: the diff is computed in the browser (`assetMetadataComparison.ts`) from the provider probe's
  `metadata` answer; the backend `OldNew[T]` diff and the refresh route it came from are gone since 1.3
  (`d5e467847`) — [[features/F-029]]. The line below on `OldNew` is the original design:
- Used `OldNew[T]` schema from `backend/app/schemas/common.py` for each diffed field
- Fields diffed: `display_name`, `currency`, `asset_type`, `classification_params` (sector, country, etc.)
- "Apply all" button sets all fields to provider values; individual toggles per field also available
- The accepted values only fill the form; they are stored when the user saves the asset (`PATCH /assets`, bulk)
