# F-045 — Measure Tool 2-click delta

## What it does
A 2-click measurement overlay that lets users mark two points on any chart and instantly see the delta between them: absolute difference (Δabs), percentage change (Δ%), number of calendar days, and annualized return. Rendered as a dotted orange line with pin (start) and arrow (end) markers. Managed exclusively by `MeasurePanel.svelte` — not in the signal dropdown.

## Layer breakdown
**Frontend**: `frontend/src/lib/charts/signals/MeasureSignal.ts`, `frontend/src/lib/components/charts/MeasurePanel.svelte` (569 lines)

## Implementation notes
- `signalType`: `measure`, `category`: `measure` (not in registry dropdown)
- **Parameters**: `startDate` (string), `endDate` (string) — dates of the two clicked points
- `MeasurementResult` interface: `startDate`, `endDate`, `startValue`, `endValue`, `deltaAbs`, `deltaPct`, `days`, `annualizedPct`
- Default style: color `#f97316` (orange), `lineWidth: 1`, `lineType: 'dotted'`, `markerStart: 'pin'`, `markerEnd: 'arrow'`
- Not registered via `@register_provider` — `MeasurePanel` creates it directly via `new MeasureSignal(...)`

## Annual rate and zero start (CP-14b, 2026-10-17)
Both copies (`getMeasurement` for the chart line, `getMeasurementForSignal` for the overlays) use two helpers.
- **Δ%** (`changePct`) is null when the span opens at zero (night decision N65): the move is unknown, and 0 % was a
  wrong number. The panel shows a muted `—`, and the compact label turns neutral (`null >= 0` is true in JS, so
  without that the `—` would be green).
- **Δ%/yr** (`annualizedChangePct`) is null:
  - under `MIN_ANNUALIZATION_DAYS` (30). That is the backend home's floor (`_MIN_ANNUALIZATION_DAYS`,
    `financial_math/returns.py`, T-D9 / D-9), held to it by a parity test that reads `returns.py`;
  - without a Δ%;
  - for a negative growth factor (the line ends on the other side of zero: no compounded rate, though 73 or 365 days
    gave a finite −103 % / −150 %);
  - when the result is not finite.
- A fall to exactly zero keeps −100 %/yr: the home's «≤ −100 %» rule is deliberately not adopted.
- The user pages (assets and FX measures, 4 languages) say so. The FX tip about 1 % in 7 days ≈ 68 %/yr now explains
  the 30-day wait.
- A second copy of the Δ% rule, the chart tooltip's `buildDeltaHtml` (`priceChartHelpers.ts`), still gives 0 % on a
  zero first value: J-44, to be routed.
