# F-063 — dev.py CLI

## What it does
The single entry point for all development operations in LibreFolio. A Python CLI using `argparse` with `argcomplete` for shell autocompletion. Covers server management, database operations, frontend build, API client sync, testing, linting, i18n management, MkDocs documentation, and Docker operations.

## Implementation notes
- Autocompletion: `eval "$(register-python-argcomplete dev.py)"` in shell RC
- Key command groups: `server`, `db`, `front`, `api`, `test`, `i18n`, `mkdocs`, `docker`, `lint`, `format`
- `./dev.py server` — starts uvicorn dev server
- `./dev.py db create-clean` — drop + recreate a fresh DB (fresh installs and test runs); schema changes ship as incremental migrations (`db migrate`, `db upgrade`) since the release — see [[concepts/single-migration-strategy]]
- `./dev.py db current|check|migrate|upgrade|downgrade [path]` — the optional path really reaches Alembic since 2026-10-09 ([[problems/db-path-argument-ignored-by-alembic]])
- `./dev.py api sync` — regenerates TypeScript Zodios client from OpenAPI schema
- `./dev.py i18n audit|add|remove|update|search` — i18n key management
- `./dev.py docker build` — full build pipeline: rebuilds the frontend and the docs when missing or stale, refreshes the JS cache, `requirements.txt` and `VERSION`, then builds the image
- **Runtime lanes** (2026-09-10): `server --port --data-dir`, `test --test-port --data-dir` — [[concepts/runtime-lanes]]
- **Inside the Docker image** (2026-10-08): command groups whose files the image does not ship (`test`, `i18n`, `mkdocs translate*`) are listed as "not available in this installation" and exit 2; `user *`, `info`, `db current|check` work through `docker compose exec` — [[problems/devpy-unusable-in-docker-image]]
