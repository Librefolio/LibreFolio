# F-065 — JWT Cookie Auth stateless

## What it does
Stateless JWT-based authentication delivered via HttpOnly cookies. The JWT payload contains only the `user_id`; the user record is fetched from the database on every request. This design works correctly with multiple uvicorn workers — no shared session store required. The cookie TTL is configurable via `GlobalSetting.session_ttl_hours`.

## Layer breakdown
**Backend**: `backend/app/services/auth_service.py` (`create_jwt_token()`, `decode_jwt_token()`, `hash_password()`, `verify_password()`), `backend/app/api/v1/auth.py` (`SESSION_COOKIE_NAME = "session"`, cookie config constants)

## Implementation notes
- Cookie: name `session`, HttpOnly=True, SameSite=lax; **`Secure` follows `SESSION_COOKIE_SECURE`** (`auto` |
  `always` | `never`, default `auto`, since 2026-10-09): `auto` sets Secure on HTTPS or when the first
  `X-Forwarded-Proto` value is `https` — the header can only turn it on, never off (`session_cookie_secure()` in
  `auth.py`). Before that the cookie was never Secure. Admins are warned when the browser uses HTTPS and the cookie
  is not Secure ([[features/F-102]]).
- JWT payload: `sub` = the user's integer id as a string (not a UUID) — minimal surface area
- `decode_jwt_token()` returns `user_id` or `None` on expiry/invalid
- Password hashing: `bcrypt` directly (`bcrypt.checkpw`; passlib is not used); an unknown login is checked against
  a dummy hash of the same cost ([[problems/login-account-enumeration-before-password]])
- `SESSION_COOKIE_MAX_AGE = 60 * 60 * 24` (24h default) — overridden by `session_ttl_hours` global setting
- Stateless: no Redis, no DB session table — scales horizontally
- **Shared secret**: every uvicorn worker must sign with the same `JWT_SECRET`. `dev.py` generates one when the
  environment has none — and since 2026-10-09 an **empty or blank** value counts as none: `JWT_SECRET=` in `.env`
  reached the environment as `''`, each worker then generated its own secret, and users were logged out whenever a
  request landed on another worker (`_ensure_shared_jwt_secret`, `c529b3147`). The Docker image runs a single
  uvicorn worker, so a per-process secret only means that a restart logs everyone out.
