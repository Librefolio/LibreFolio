# F-069 — MkDocs Multi-Language Documentation

## What it does
LibreFolio's formal user and developer documentation built with MkDocs Material. Supports four languages (EN/IT/FR/ES) via a suffix strategy (`.en.md`, `.it.md`, `.fr.md`, `.es.md`). Sections: user manual, admin manual, developer reference, financial theory (with LaTeX/KaTeX), and UI screenshot gallery. Served from `mkdocs_src/site/` inside the Docker image.

## Layer breakdown
**Infra**: `mkdocs_src/mkdocs.yml` (main config), `mkdocs_src/docs/` (source files), `mkdocs_src/site/` (build output, gitignored), `mkdocs_src/aphra-pipeline/` (LLM translation pipeline scripts)

## Implementation notes
- Suffix strategy: all new docs written in EN (`.en.md`), translations generated by Aphra pipeline
- Developer docs (`docs/developer/`) are EN-only by design
- MkDocs Material features: Mermaid diagrams, LaTeX via KaTeX, admonitions, custom gallery JS
- Admonition rule: **always** empty line between `!!!`/`???` directive and body (Prettier-safe)
- Gallery images served dynamically: `{basePath}/gallery/{viewport}/{lang}/{theme}/{category}/{name}.png`
- Commands: `./dev.py mkdocs build|serve|translate|translate-diff`
- **1.2 English alignment** (workstream Q, 2026-10-07 → 10-10): user pages plain, technical detail in the developer
  manual, a named placeholder for every missing screenshot, no translation stamped —
  [[decisions/user-docs-plain-dev-manual-technical]]; rewriting from the code found pages that promised what the code
  did not do — [[problems/docs-claimed-what-the-code-did-not-do]]
- An English-only page (the developer manual) links translated pages without anchors: a strict translated build checks
  the anchor in the translated page. Q met it on the Tools pages, then not yet translated —
  [[decisions/docs-anchors-from-the-render]]
- The gallery's image fallback reads the canonical site URL (`overrides/main.html`), since `mkdocs serve` rewrites
  `site_url` to the local address (`bb48d7e0a`)
- The local MathJax is found from the loader script's own address: until `8d47c28c0` (2026-10-12) nested pages
  fetched it from jsDelivr and showed no formulas offline — [[problems/docs-mathjax-looked-in-the-page-folder]] (M-19;
  M-21, a local site not rebuilt after a JS- or CSS-only change, is still open); its fonts came along in batch 25, as
  companions of the vendored script — [[problems/mathjax-fonts-missing-from-local-copy]]; since train 70 both are
  pinned by `front-utility docs-offline-math`; Mermaid still needs internet (M-22, after 1.2)
- Table styles go through a wrapper class in `static/extra.css`: Material's own table rules win otherwise —
  [[problems/mkdocs-material-tables-resist-styling]]
