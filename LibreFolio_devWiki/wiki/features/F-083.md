# F-083 — Multi-File Multi-Broker Import

## What it does

Allows one import-wizard session to upload, select, parse, reconcile, and review files
belonging to several brokers before staging the chosen rows in one bulk workspace.

## Dependencies

- [[F-012]] BRIM Framework — file, parse, candidate, and duplicate APIs.
- [[F-013]] BRIM Plugins — one selected parser per file.
- [[F-049]] BRIM Import UI — cross-file identity and duplicate review.

## Implementation notes

- Every uploaded file has one broker assignment; the session may contain many such files.
- Upload requests are bounded-concurrent. Parsing is currently sequential in the wizard,
  so progress and per-file failures remain deterministic.
- Each plugin allocates placeholders from the same positive high fake-ID base. The merge
  remaps them per file before grouping, preventing cross-file collisions.
- Candidate search, duplicate recheck, and broker-opening gates are evaluated against the
  current merged drafts before handoff.
- The bulk editor receives drafts in merge order. Its chronological sort is display-only:
  stable draft identity, pairing, selection, validation indices, and payload order remain
  independent.
