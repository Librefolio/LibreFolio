# F-084 — Transaction Gain Chart

## What it does
A chart showing per-buy-lot gain/loss over time with a dual Y-axis. For each open position, the gain is tracked from purchase date. Includes a FIFO/LIFO/PMC selector to switch the cost-basis method for visualization.

## Implementation notes
- Dual Y-axis: left=price, right=gain%
- Per-buy lot gain tracking requires FIFO/LIFO/PMC calculation per lot
- Phase 8 target — requires transaction model (Phase 7) to be complete
- *2026-11-07 lint*: part of this exists in the **Lots Analysis** of the Dashboard and broker Positions tabs
  (`frontend/src/lib/features/brokers/lots/`, `POST /portfolio/lots/analysis`): `LotComparisonChart.svelte` draws
  the value and return of selected lots over time, and `LotWacPriceChart.svelte` the price against the average cost —
  developer page `developer/frontend/components/features/lots-analysis.md`. The FIFO/LIFO/PMC selector is not built
  (it waits on [[F-081]]); no feature code covers the Lots Analysis itself
