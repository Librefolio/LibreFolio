# F-087 — Smooth Signal Line Style

## What it does
Adds a cubic spline ("smooth") rendering option for signal overlay lines in the chart. Currently all signal lines use linear interpolation between data points. A smooth option would use cubic spline for a more aesthetic curve.

## Implementation notes
- ECharts `series.smooth: true` for built-in smoothing
- Add `smooth` param to `ChartSignal` base class or per-signal style config
- Low priority — aesthetic improvement only

## Delivered in another form (2026-10-30, `610c6af4d`, recorded by the 2026-11-07 lint)
Not a per-signal option: a **line shape** setting for every chart (FB-3) — `segments` (default), `steps` or `spline`
(a monotone smooth curve, `smooth` with `smoothMonotone: 'x'`; a free spline is refused because it draws values that
never existed). `frontend/src/lib/components/charts/lineShape.ts` (`applyLineShape`) is applied by `PriceChartFull` to
all its series, the signal overlays included (`buildOverlaySignalSeries`); the choice is `lineShape` in
`chartSettingsStore.svelte.ts`, picked with `LineShapePicker.svelte`. CHANGELOG 1.3: «Choose the shape of your chart
lines … segments (the default), steps or a smooth spline, for every chart.»
