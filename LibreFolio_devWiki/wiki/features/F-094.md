# F-094 — Sync Date Range Dialog

## What it does
A date range selector dialog shown before data sync operations (both FX and Asset). The dialog warns the user if the selected range would overwrite existing data and lets them choose a narrower range for targeted re-sync.

## Implementation notes
- Applies to both FX Sync All modal and Asset sync controls
- Warning banner when selected range overlaps existing data
- Medium priority

## Delivered (checked on 2026-10-12, C-64)
One sync dialog, `SyncModalBase`, shows the range it is about to sync, then the progress, a result per item and the
retries. Three dialogs build on it, and each syncs the date range of the page that opens it — from the earliest date
(`'min'`) when the page shows MAX: `FxSyncModal` on the FX page, `AssetSyncModal` on the Assets list, `PageSyncModal`
on the detail pages of an asset and of a pair (asset prices and FX rates in one dialog, an empty section hidden). The
range is chosen on the page, not in the dialog.

## Still open — C-66 (`BACKLOG_POST_1.2.md`)
