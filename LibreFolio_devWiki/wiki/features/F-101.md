# F-101 — Global privacy mode ("hide values")

## What it does
An eye button in the header hides every personal amount of money in the app — `+•••` / `-•••` in place of the
number, with the sign and the currency kept — so LibreFolio can be opened in public or on a projector.
Percentages, market prices and counts stay visible; quantities are hidden next to a price (positions, lots) and
visible in transactions. The choice belongs to the device and survives closing the browser.

## Layer breakdown
**Frontend only**: `PrivacyToggle.svelte` (header) flips `privacyStore` (localStorage key `librefolio-privacy`);
the currency formatters consult `maskable.ts` before producing the string; charts include the privacy state in
their rebuild key. No backend change: the API still returns real values (declared limit D4).
