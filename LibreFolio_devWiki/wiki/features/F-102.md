# F-102 — Connection security indicator

## What it does
A shield in the sidebar tells the user whether the connection to their LibreFolio is **secure** (HTTPS, localhost,
a VPN), **local** (a LAN, or a case the app cannot settle) or **insecure** (plain HTTP over the internet), with a
details panel and a link to the user documentation. Administrators also get a warning when the browser uses HTTPS
but the session cookie was set without `Secure`.

## Layer breakdown
**Backend**: `GET /api/v1/system/connection` returns the client address *class* and the cookie decision — never the
address (`backend/app/api/v1/system.py`, `backend/app/utils/network_utils.py`). The session cookie's `Secure`
attribute follows `SESSION_COOKIE_SECURE` (`auto|always|never`).

**Frontend**: `connectionSecurity.ts` (verdict), `connectionSecurityStore.ts`, `ConnectionSecurityIndicator.svelte`
in the sidebar; translations under `connectionSecurity.*`.

## Dependencies
- [[F-001]] / [[F-065]] — the session cookie whose `Secure` attribute the admin line reports.
- [[F-004]] — the app shell (sidebar, header).

## Implementation notes
