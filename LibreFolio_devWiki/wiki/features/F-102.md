# F-102 — Connection security indicator

## What it does
A shield in the sidebar tells the user whether the connection to their LibreFolio is **secure** (HTTPS, localhost,
a VPN), **local** (a LAN, or a case the app cannot settle) or **insecure** (plain HTTP over the internet), with a
details panel and a link to the user documentation. Administrators also get a warning when the browser uses HTTPS
but the session cookie was set without `Secure`.

## Layer breakdown
**Backend**: `GET /api/v1/system/connection` returns the client address *class* and the cookie decision — never the
address (`backend/app/api/v1/system/connection.py`, `backend/app/utils/runtime/network.py`; `utils/network_utils.py` until
2026-10-12). The session cookie's `Secure`
attribute follows `SESSION_COOKIE_SECURE` (`auto|always|never`).

**Frontend**: `connectionSecurity.ts` (verdict), `connectionSecurityStore.ts`, `ConnectionSecurityIndicator.svelte`
in the sidebar; translations under `connectionSecurity.*`.

## Dependencies
- [[F-001]] / [[F-065]] — the session cookie whose `Secure` attribute the admin line reports.
- [[F-004]] — the app shell (sidebar, header).

## Implementation notes
The verdict rule — the server may confirm or make uncertain, never make secure — and the privacy of the client
address: [[decisions/connection-security-server-never-upgrades]]. Shipped with the login enumeration fix:
[[problems/login-account-enumeration-before-password]].

The guide, reviewed by the developer in a live preview on 2026-10-12 (M's batch 23, `11339afa6`): each level is a
two-column table, equal on every screen — «✅ Pro | ⚠️ Con» on the green and red levels (the red «Pro» cell says
«None.»), «🤷 You settle for | ⚠️ Con» on the local one — with «👉 What to do» under it
([[problems/mkdocs-material-tables-resist-styling]]). Tailscale over plain HTTP is a warning, not a «Con»: as a risk it
equals HTTPS (the developer: «a livello di rischio, sono uguali»), but the browser will not install the app over it.
Checking that claim, `docs-writer` found five copy buttons that also fail there —
[[problems/copy-buttons-without-http-fallback]] (M-20, open). `admin/docker_advanced` and the `SESSION_COOKIE_SECURE`
panel of `admin/configuration` now point to `admin/connection_checks`, whose checklist the developer approved, asking
only to drop its «se vuoi» («leva i vari "se vuoi" ma mi pare un ottimo lavoro»).
