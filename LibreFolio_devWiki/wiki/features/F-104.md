# F-104 — Recommend LibreFolio (social share)

## What it does
In *About* and in the donation popup, a "Support LibreFolio" card offers, besides the coffee link, one share button
per network — X, Reddit, Facebook, Instagram, TikTok. A button opens a **Share on …** dialog with a suggested
message written for that platform (in EN/IT/FR/ES; a separate title for Reddit) and a **Copy and go** button: the
message is copied first, then the platform's composer opens in a new tab. The fixed public project URL is always
included; the instance's URL and any user data never are.

Domain: [[domains/layout-settings]].

## Layer breakdown
**Frontend only**: `frontend/src/lib/components/support/` — `supportLinks.ts` (platform order, intent URLs,
public project URL), `shareNavigation.ts` (new tab with `opener = null`, `noopener noreferrer`),
`SocialShareModal.svelte`, `SocialIcon.svelte` (CC0 Simple Icons), `SupportActions.svelte`.

## Implementation notes (Release 2 urgent import feedback, rounds 2–4, September 2026)
- **Copy-and-go ordering**: the clipboard write starts before a blank tab is reserved, inside the same click; if the
  copy fails, nothing navigates; on plain HTTP the fallback is a checked `execCommand`; the toast confirms the copy,
  not that anything was published.
- **Platform boundaries (Round 4 decisions)**: Facebook's sharer takes a link only (`quote` rejected); Instagram has
  no reliable web composer — `/create/select/` was rejected because it resolves to a profile page, so the button opens
  the site root; TikTok opens `/upload`; the Web Share API was rejected because it cannot target a specific app.
- Badges are fixed at 40×40 with `shrink-0`; each button carries the platform's colour.
