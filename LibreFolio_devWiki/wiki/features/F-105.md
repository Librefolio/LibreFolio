# F-105 — Guided onboarding

## What it does
A new account lands on a **Welcome** page (language, base currency, optional avatar, pre-filled with the
administrator's defaults), then a short **intro tour** of the navigation, then **contextual guides** that start the
first time the user reaches a page, an *Add* modal, a detail view, the Import Wizard or the bulk workspace. A guide is
a sequence of coachmarks pointing at real controls; it never acts for the user. Every guide can be skipped for good
and replayed from Settings → Preferences → Onboarding.

Domain: [[domains/layout-settings]].

## Layer breakdown
**Backend**: one versioned progress row per user and flow (`user_onboarding_progress`) plus one row per step of the
two step-managed flows (`user_onboarding_step_progress`), both created by migration `004_release_1_2_0_schema.py`.
`backend/app/services/onboarding_service.py` holds the registry (`ONBOARDING_FLOW_VERSIONS`, `ONBOARDING_FLOW_STEPS`)
and the transitions; `backend/app/api/v1/settings.py` exposes `GET /settings/onboarding` and the `complete`/`skip`
endpoints per flow and per step, all carrying `expected_version` (409 on a mismatch).

**Frontend**: the engine `onboardingGuide` (`onboardingGuide.svelte.ts`), the catalogue
(`onboardingGuideCatalog.ts`), the anchor registry and its `guideAnchor` action (`guideAnchors.svelte.ts`), the
bootstrap and Welcome redirect (`appBootstrap.svelte.ts`, `onboardingRouteSettlement.ts`), the overlay host and the
coachmark, the replay list in Settings, and `DeferredAppPopups.svelte`, all under
`frontend/src/lib/features/onboarding/` (the components moved there from `lib/components/onboarding/` in `93e023f2e`,
2026-10-11). The controller with the server progress and the stored positions is
`frontend/src/lib/stores/app/onboarding.svelte.ts`.

## The fifteen flows
`welcome` (a page) and fourteen guided flows, all at **version 1**: `intro_tour` (9 step ids — the intro scene and
eight coachmarks on the navigation), a page, an Add-modal and a detail guide each for Brokers, FX and Assets,
`transactions_page_guide`, `transaction_create_guide`, and the two step-managed flows `import_guide` (9 steps,
`import.gapFix` included) and `transaction_bulk_guide` (4 steps, checkpoint navigation). The step-managed flows
persist each step on the server; the owning component decides which step is current.

## Dependencies
- [[F-004]] App shell — the `(app)` layout gate redirects to `/welcome` while Welcome is due, makes the shell
  `inert` during the intro tour, and mounts `DeferredAppPopups`.
- [[F-005]] User settings — Welcome saves the language, currency and avatar; the replay list lives in Preferences.
- [[F-008]] i18n — every step text in four languages; Welcome previews the chosen language at once
  ([[problems/i18n-loading-gate-remounts-app]] was found on that path).
- [[F-092]] Default language/currency for new users — Welcome starts from the administrator's defaults.

## Implementation notes
- **Progress model**: [[decisions/onboarding-versioned-progress-per-flow]]. **Accounts older than 1.2.0**:
  [[decisions/onboarding-existing-users-seeded-skipped]].
- **Ground rules** (the four of the developer doc, enforced by the skill
  `.github/skills/onboarding-tools/onboarding-guide/SKILL.md`): the guide observes and never acts
  ([[decisions/onboarding-guide-observes-never-acts]]); anchor only what is rendered
  ([[problems/guide-anchor-never-resolves]]); a step never announces another guide
  ([[decisions/guide-text-never-announces-another-guide]]); pages talk to the engine, not to the stored state.
- **Positions**: per account, flow and version in `localStorage`; a guide resumes at its step, survives logout and
  closes in every tab when it ends — [[decisions/onboarding-positions-in-browser-per-account]].
- **Popups**: the donation and update prompts wait while a guide or a modal is on screen; a requested update check
  opens at once — [[decisions/automatic-popups-wait-for-guides]].
- **Geometry**: a target is used only after two identical frames, with the nearest `.modal-content` as motion root —
  [[problems/coachmark-measured-mid-modal-transition]]. The layout gate reads the bootstrap through `toStore()` —
  [[problems/legacy-layout-gate-missed-runes-state]].
- **The Import guide** follows the wizard's real steps (`startImportAt()` in `ImportWizardModal.svelte`) and hands
  `import.bulk` to the bulk editor; only the user's Save All commits — see [[entities/import-wizard-modal]].

## Dead ends / Ideas explored
- **Three surfaces became fifteen flows.** The brief (SP11/U8) asked for a Welcome page, one tour and one import guide;
  Rounds 2–5 generalised it into a catalogue. Round 2 split Broker, FX and Asset into contextual guides on the
  developer's feedback; the review dossier written by workstream J counts the rest of the generalisation as its own
  judgement, and lists every choice the brief did not make, with how to reverse it. The developer approved the UX on
  2026-09-14 («ok chat, ho visionato un pò tutto e non ho visto problemi! mi piace!») —
  [[sources/phase00-onboarding-2026-09]].
- **Three Bulk flows** (Round 4, the developer's choice «più guide Bulk persistite separate») went back to one flow
  with per-step progress in Round 5, on the developer's feedback.
- **Modal previews in the tour** (Round 1): the create modals opened as non-writing previews. Since Round 2 an Add
  guide starts only on a real click; `onboardingTourSurfaces.svelte.ts` keeps preview handlers that no component
  registers (developer doc note).
- **Session-scoped replays** (`sessionStorage`, Rounds 1–7) gave way to positions in `localStorage` (Round 8).
- **A shorter intro tour** (dossier §6 #9) — closed by the developer on 2026-10-09: «il tour iniziale va bene già ora,
  toglilo».

## Still open
From the main plan's «Cosa resta aperto» (updated 2026-10-11): no test compares the TS flow list with the Python
registry; the version-bump re-trigger has never run end to end; the 641–1023 px band is untested; no admin or CLI
reset of a user's onboarding; no telemetry; the `tools.hub` anchor (the Tools hub of [[features/F-106]]) is not used
by any guide.
