# F-109 — In-app changelog

## What it does
The version number at the bottom of the sidebar, and the version label under the title of Settings → About, open a
modal with the changelog bundled in the app: one foldable panel per release, then per section and sub-section, with
a search, expand and collapse, and a link to the file on GitHub. Since 2026-10-12 each release is shown in the
interface language when its translation exists; a release not yet translated appears in English, with a small
**Not translated yet** label.

## Layer breakdown
**Frontend**: `features/changelog/changelog.ts` parses `CHANGELOG.md` (bundled inline) into chapters and sections and,
since the localization, merges the translated chapters of `CHANGELOG.<xx>.md` (one lazy chunk per language);
`ChangelogModal.svelte` renders them through `sanitizeHtml`; the modal is opened from `Sidebar.svelte` and from the
About tab.

**Repository**: `CHANGELOG.md` at the root, written under the «Changelog Rules» of the Copilot instructions; the
translated files `CHANGELOG.{it,fr,es}.md` are workstream M's, with the same `## [x.y.z] - date` lines.

## Dependencies
- [[F-004]] — the sidebar's version number opens it.
- [[F-008]] — the UI language picks the translation; `changelog.notTranslated` is the label of an English chapter.

## Implementation notes
- Introduced with the beta feedback round (`3e3f9c41f`, 2026-09-01).
- Localized by workstream T (CL of plan 43, `8f67f89de`): the English file stays the authority on which releases exist
  and in what order; a translated chapter replaces its English twin only when it has content —
  [[decisions/changelog-translated-by-chapter]].
- `dev.py` rebuilds the frontend when any `CHANGELOG*.md` is newer than the build (`ee8a19384`); a deleted translation
  is not seen by modification times, so it needs an explicit `front build`.
- **Still open — M-23** (planned in 1.2): the French chapters keep plain spaces, which MkDocs replaces with no-break
  spaces only on documentation pages; the modal needs the same rules — [[decisions/fr-typography-at-build-time]].
