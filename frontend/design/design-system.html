Il design system di LibreFolio

Catalogo estratto direttamente dal codice sorgente (SvelteKit + Tailwind v4) e verificato a runtime: token colore, tema chiaro/scuro, tipografia, oltre 60 componenti UI e il sistema di 4 lingue. Pensato come riferimento per chi progetta nuove schermate o briefa un designer esterno.

Svelte 5 + SvelteKit Tailwind CSS v4 lucide-svelte icons svelte-i18n ECharts

Brand & palette app.css — @theme

Il verde bosco libre-green è il colore d'identità in ogni schermata: header di login, azioni primarie, grafici positivi. Il beige caldo libre-beige è lo sfondo di base in tema chiaro.

Colori semantici (feedback & azioni)

Distinti dall'accento di brand: usati in banner, toast e pulsanti di azione destructive/attenzione. Basati sulla palette standard Tailwind (amber/blue/red/emerald), non sulla scala di brand.

Tema chiaro / scuro html.light / html.dark

Il tema non è gestito da Tailwind dark: soltanto — un secondo strato di custom property semantiche (--theme-bg-*, --theme-text-*, --theme-border-*, --theme-accent) viene ridefinito su html.dark, applicato tramite selettori che sovrascrivono le utility Tailwind più comuni (es. html.dark .bg-white). Uno script anti-FOUC in app.html imposta la classe prima del primo paint.

Layout responsivo PageToolbar — pattern a 4 livelli

Il pattern più distintivo del sistema: la toolbar di ogni pagina (filtri, riepilogo, azioni, tab) non segue i breakpoint di viewport ma un ResizeObserver sul proprio contenitore, per restare corretta anche dentro layout annidati o pannelli stretti. Quattro livelli, ciascuno con soglia dedicata:

oneRow

Filtri + riepilogo + azioni sulla stessa riga, spazio pieno.

denseRow

Stessa riga, ma etichette delle azioni iniziano a restringersi.

stackFilters

Filtri+riepilogo impilati in colonna; azioni restano a fianco come colonna 4×1.

oneColumn

Tutto impilato: filtri, riepilogo e azioni (griglia 2×2) in un'unica colonna.

Le etichette lunghe (es. francese "Vue d'ensemble") non vengono nascoste ma rimpicciolite in blocco con una scala lineare misurata a runtime (labelShrink.ts) — coerente con l'attenzione all'i18n del prodotto.

Catalogo componenti frontend/src/lib/components/ui

Non esiste un Button.svelte atomico: i pulsanti sono classi scoped per-componente (.btn-primary, .btn-danger …) che riusano gli stessi hex in tutta l'app. I componenti condivisi coprono invece i pattern con logica ricorrente — dropdown, modali, date picker, editor tabellari.

01

Modali

ModalBase

Backdrop + transizione fade/scale, focus trap, body-scroll lock condiviso tra modali impilate, chiusura su Escape/click-fuori.

z-index 50/60/70
ConfirmModal

Conferma generica con varianti danger/warning, lista collassabile di elementi, riepilogo risultati per-azione dopo l'esecuzione.

SyncModalBase / PageSyncModal

Base per modali di sincronizzazione broker con stato di avanzamento.

02

Select & dropdown

BaseDropdown

Logica headless (apertura, click-fuori, tastiera) riusata da SimpleSelect e SearchSelect.

SimpleSelect

Dropdown posizionato in position:fixed per non essere tagliato da contenitori con overflow — usato ovunque servano opzioni statiche.

SearchSelect

Variante con ricerca, alla base di AssetSelect, BrokerSearchSelect, CountrySearchSelect, CurrencySearchSelect, SectorSearchSelect.

03

Feedback

InfoBanner

4 varianti (info/warning/error/success), icona lucide dedicata, dismiss opzionale.

ToastContainer

Notifiche top-center con barra di countdown animata prima dell'auto-dismiss.

Tooltip

Hover istantaneo o "pinnato" al click con grazia di 5s prima di richiudersi; supporta HTML e LaTeX inline (KaTeX); portale su document.body per non essere tagliato.

LoadingSpinner

Indicatore centrato, 3 taglie (sm/md/lg), testo i18n di default.

04

Tab & toolbar

TabBar

Tab con indicatore verde, badge numerico opzionale, shrink-to-fit delle etichette via ResizeObserver.

PageToolbar

Guscio a 4 zone (Filtri · Riepilogo · Azioni · Tab) — vedi sezione Layout responsivo.

05

Data & display

BrokerBadge

Icona broker con catena di fallback: icona custom → favicon del portale → icona del plugin → icona di sistema.

DataEditor / CsvEditor

Griglia editabile per import dati storici, con celle numeriche "cancellabili" (vedi ErasableNumberCell).

ErasableNumberCell

Cella numerica con sentinella -1 = "valore azzerato dall'utente", distinta da null = "non impostato".

OrderableList / ContextMenu

Liste riordinabili e menu contestuali generici.

06

Date

SingleDatePicker

Trigger con icona calendario + popover a mese singolo, click = seleziona e chiudi.

DateRangePicker

Selezione intervallo, si aggancia ai filtri periodo (1W…10Y, YTD, Custom) presenti in ogni pagina.

CalendarMonth

Griglia mese con etichette giorni/mesi completamente i18n.

07

Input & media

PasswordInput

Toggle mostra/nascondi con icona Eye/EyeOff, stato errore.

PasswordStrength / TagInput / DistributionEditor

Input specializzati per registrazione, tag liberi, ripartizioni percentuali.

ImageCropper / ImageEditModal

Ritaglio immagine (cropperjs) per avatar e allegati.

FileUploader / LazyImage

Upload file e immagini con caricamento lazy.

08

Grafici

LineChart / CandlestickChart

Basati su ECharts, con zoom sincronizzato e pan touch dedicato.

AllocationPieChart / SemiDonutChart / GeographyMap

Visualizzazioni di allocazione per tipo/settore/geografia.

Signal system

SignalTreeSelect, SignalStyleEditor, MeasurePanel — overlay di indicatori configurabili sopra i grafici prezzo.

09

Tema & lingua

ThemeToggle

Icona Moon/Sun in header, sincronizzata con il themeStore centralizzato.

LanguageSelector

Dropdown con bandiera + nome lingua, persiste su localStorage.

ViewModeToggle

Cambio vista griglia/lista (usato in Assets).

Note per l'uso di questo documento

Perché non è un progetto claude.ai/design: lo skill /design-sync compila i componenti come React (shim su window.React/ReactDOM); LibreFolio è Svelte 5, quindi i componenti reali non possono essere renderizzati da quel runtime. Ricrearli come cloni React avrebbe violato il principio "mai una reimplementazione" dello skill. Questo documento è quindi un riferimento statico, non un ambiente di prototipazione live.

Fonti: frontend/src/app.css, frontend/tailwind.config.js, frontend/src/lib/components/ui/**, frontend/src/lib/i18n/**, più verifica a runtime su dev.py server (DB di produzione).
