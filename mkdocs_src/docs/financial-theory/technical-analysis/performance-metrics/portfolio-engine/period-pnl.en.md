# 📊 Period PnL (Profit and Loss)

*[⬅️ Back to Performance Metrics Overview](../index.md)*

## 💡 What is Period PnL?

The absolute monetary gain or loss generated by your portfolio within $[t_0, t_1]$, adjusted for external cash flows.

---

## 🧮 Formula

$$
\boxed{
\mathrm{PnL}_{\text{period}} =
\mathrm{NAV}(t_1)-\mathrm{NAV}(t_0)
-\Delta \mathrm{CapitalBaseline}_{[t_0,t_1]}
}
$$

The baseline delta comes from `cumulative_external_cash_flow`, so it includes cash flows and priced in-kind ADJUSTMENT/TRANSFER capital.

---

## 🧮 Decomposition

$$
\mathrm{PnL}_{\text{period}} = \Delta\mathrm{UGL} + \mathrm{Realized} + \mathrm{Income} - \mathrm{FeesTaxes} + \mathrm{Other}
$$

| Component | Definition |
|-----------|-----------|
| $\Delta\mathrm{UGL}$ | Change in unrealized gain/loss over the period |
| Realized | Sum of (sell proceeds − cost basis) for SELLs in period |
| Income | DIVIDEND + INTEREST in period |
| FeesTaxes | FEE + TAX in period |
| Other | Residual that closes the identity |

The residual is computed as:

$$
\mathrm{Other}=
\mathrm{PnL}_{\text{period}}
-\Delta\mathrm{UGL}
-\mathrm{Realized}
-\mathrm{Income}
+\mathrm{FeesTaxes}
$$

---

## 🎯 Per-Asset Contribution

For each position $(a,b)$:

$$
\mathrm{PnL}(a,b) = \Delta\mathrm{UGL}(a,b) + \mathrm{Realized}(a,b) + \mathrm{Income}(a,b) - \mathrm{FeesTaxes}(a,b)
$$

The position set includes **all activity** in the period:

$$
\mathcal{P} = \text{positions with BUY/SELL/ADJUSTMENT/TRANSFER activity or boundary quantity}
$$

Annualized period return clamps its window start to the later of the requested start and the oldest open lot date. It uses $|\mathrm{StartValue}|$ as annualization base, falling back to end cost basis for positions opened mid-period. See [Net Annualized Return](net-annualized-return.md).

🔗 See **[Portfolio Engine — §7 Period Contribution](index.md#7-period-contribution)** for details.

---

## 📝 Example

- NAV at $t_0$: €27,000
- Capital baseline increase in period: €1,000
- NAV at $t_1$: €33,000

$$
\mathrm{PnL} = 33\,000 - 27\,000 - 1\,000 = +5\,000 \text{ EUR}
$$
