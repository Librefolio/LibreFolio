# 🖥️ Galería de Escritorio

Experimenta la interfaz de escritorio completa de LibreFolio. Las capturas de pantalla se adaptan automáticamente al tema y al idioma que selecciones.

!!! tip "Tema e idioma"

    Usa el **interruptor de tema** en el encabezado (☀️/🌙) para alternar entre el modo claro y el oscuro.
    Usa el **selector de idioma** (🇬🇧) en el encabezado para ver las capturas de pantalla en diferentes idiomas.

Eliminar una transacción que forma parte de un par vinculado (operación FX, transferencia) abre el **espacio de trabajo de borrado masivo**: el par se muestra como una fila colapsada previamente marcada para su eliminación, y una sugerencia de división te permite eliminar solo una de las dos operaciones en lugar de ambas.
