# 🖥️ Galería de escritorio

Experimenta la interfaz de escritorio completa de LibreFolio. Las capturas de pantalla se adaptan automáticamente al tema y idioma seleccionados.

!!! tip "Tema e idioma"

    Usa el **interruptor de tema** en el encabezado (☀️/🌙) para cambiar entre modo claro y oscuro.
    Usa el **selector de idioma** (🇬🇧) en el encabezado para ver las capturas en diferentes idiomas.
