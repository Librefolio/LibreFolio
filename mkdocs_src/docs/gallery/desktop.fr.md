# 🖥️ Galerie de bureau

Découvrez l'interface de bureau complète de LibreFolio. Les captures d'écran s'adaptent automatiquement au thème et à la langue sélectionnés.

!!! tip "Thème et langue"

    Utilisez l'**interrupteur de thème** dans l'en-tête (☀️/🌙) pour basculer entre les modes clair et sombre.
    Utilisez le **sélecteur de langue** (🇬🇧) dans l'en-tête pour afficher les captures d'écran dans différentes langues.

### 🗑️ Supprimer une paire liée

La suppression d'une transaction qui fait partie d'une paire liée (opération de change, transfert) ouvre l'**espace de travail de suppression groupée** : la paire est préparée sous la forme d'une ligne réduite pré-marquée pour la suppression, et une indication de division vous permet de n'en supprimer qu'une seule au lieu des deux.
