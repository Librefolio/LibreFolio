# 📱 Galería Móvil

Experimenta la interfaz móvil adaptable de LibreFolio. Las capturas de pantalla se adaptan automáticamente al tema y al idioma seleccionados.

!!! tip "Tema e idioma"

    Usa el **interruptor de tema** en la cabecera (☀️/🌙) para cambiar entre modo claro y oscuro.
    Usa el **selector de idioma** (🇬🇧) en la cabecera para ver las capturas de pantalla en diferentes idiomas.

!!! info "Optimizado para móvil"

    LibreFolio es totalmente adaptable y funciona muy bien en smartphones y tablets. La interfaz se adapta automáticamente a pantallas más pequeñas con un menú de navegación plegable.
