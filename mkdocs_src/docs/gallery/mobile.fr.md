# 📱 Galerie mobile

Découvrez l'interface mobile responsive de LibreFolio. Les captures d'écran s'adaptent automatiquement au thème et à la langue sélectionnés.

!!! tip "Thème et langue"

    Utilisez le **sélecteur de thème** dans l'en-tête (☀️/🌙) pour basculer entre le mode clair et le mode sombre.
    Utilisez le **sélecteur de langue** (🇬🇧) dans l'en-tête pour afficher les captures d'écran dans différentes langues.

!!! info "Optimisé pour mobile"

    LibreFolio est entièrement responsive et fonctionne parfaitement sur les smartphones et les tablettes. L'interface s'adapte automatiquement aux écrans plus petits avec un menu de navigation repliable.
