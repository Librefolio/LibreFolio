# 📱 Galleria mobile

Scopri l'interfaccia mobile responsive di LibreFolio. Gli screenshot si adattano automaticamente al tema e alla lingua selezionati.

!!! tip "Tema e lingua"

    Usa l'**interruttore del tema** nell'intestazione (☀️/🌙) per passare dalla modalità chiara a quella scura.
    Usa il **selettore della lingua** (🇬🇧) nell'intestazione per visualizzare gli screenshot in lingue diverse.

!!! info "Ottimizzato per mobile"

    LibreFolio è completamente responsive e funziona egregiamente su smartphone e tablet. L'interfaccia si adatta automaticamente agli schermi più piccoli con un menu di navigazione comprimibile.
