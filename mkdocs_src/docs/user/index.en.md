## ⭐ Core Features

- 🏦 **[Brokers](brokers/index.md)**: Create and manage brokerage accounts, upload reports, and share access with other users.
- 📂 **[Files & Uploads](files/index.md)**: Manage static resources and broker reports. Upload files, edit images.
- 💱 **[FX Rates](fx/index.md)**: Track currency exchange rates, configure data providers, set up auto-sync, and import CSV data.
- 🧰 **[Tools](tools/index.md)**: Standalone calculations that never change your portfolio. The first one, the **[PAC allocator](tools/pac-allocator/index.md)**, plans the purchases that bring a new investment as close as possible to its target allocation, without placing any order.
