# ⚙️ Paramètres

Le panneau Paramètres de LibreFolio vous permet de personnaliser l’application et, si vous êtes administrateur, de gérer la configuration globale.

Chaque utilisateur dispose de quatre onglets ; les administrateurs disposent en plus du groupe **Administration**, qui rassemble les onglets de l’instance :

- 👤 **[Profil](profile.md)** — Nom d’utilisateur, adresse e-mail, avatar, mot de passe et suppression du compte.
- 🎛️ **[Préférences](preferences.md)** — Langue, devise de base et thème.
- 🧩 **[Plugins](plugins.md)** — Ce que demandent les sources de prix et de taux de change : vos propres préférences de recherche, et les paramètres de l’instance, que seuls les administrateurs modifient.
- ℹ️ **[À propos](about.md)** — Informations de licence, numéros de version, plugins installés et journal des modifications intégré à l’application.
- 🗂️ **Administration** — Les onglets de l’instance, réservés aux administrateurs, à droite de la barre d’onglets sur un écran large :
    - ⚙️ **[Paramètres globaux](../../admin/settings.md)** — Configuration de l’instance, qui s’applique à tous les utilisateurs.
    - 👥 **[Utilisateurs](../../admin/users.md)** — Les comptes de l’instance, les invitations et les liens de réinitialisation de mot de passe.
    - 💾 **[Sauvegarde](../../admin/cli_backup.md#backup)** — Les données de toute l’instance dans une seule archive, à télécharger.
    - ✉️ **[E-mail](../../admin/email.md#email-tab)** — La possibilité pour LibreFolio d’envoyer des e-mails, ainsi qu’un e-mail de test.
    - 🛡️ **Sécurité** — Comment l’instance est configurée, et ce qui demande attention en premier : voir « Sécurité » dans [Paramètres globaux](../../admin/settings.md).

---

## 🗂️ Le groupe Administration {: #administration }

Seuls les administrateurs disposent de ce groupe. Cliquez sur **Administration** pour ouvrir son premier onglet, **Paramètres globaux** : une seconde rangée d’onglets apparaît alors sous la première, avec **Paramètres globaux**, **Utilisateurs**, **Sauvegarde**, **E-mail** et **Sécurité**. Cliquer de nouveau sur **Administration** alors que l’un de ces onglets est ouvert vous maintient sur cet onglet.

- 👤 **Vous n’êtes pas administrateur ?** Vous ne disposez pas du groupe **Administration** : vos onglets se terminent par **À propos**, et un lien vers l’un des onglets d’administration ouvre votre **Profil** à la place. Les paramètres de l’instance continuent de s’appliquer à vous : c’est votre administrateur qui les modifie.
- 🔢 **Le nombre affiché sur Sécurité**, repris sur **Administration**, indique combien de points les contrôles de sécurité de l’instance demandent à un administrateur d’examiner.
- 📱 **Sur un téléphone**, les onglets n’affichent que leurs icônes, et le titre au-dessus indique l’onglet ouvert.

## ↔️ Quand les onglets ne tiennent pas {: #tabs-overflow }

Dans une fenêtre étroite, ou dans une langue aux noms plus longs comme le français ou l’espagnol, une rangée d’onglets peut être plus large que le panneau. La rangée défile alors horizontalement et s’estompe de chaque côté là où d’autres onglets sont masqués. Lorsque vous ouvrez un onglet, que vous redimensionnez la fenêtre ou que vous changez de langue, la rangée défile de manière à ce que l’onglet ouvert soit entièrement visible.
